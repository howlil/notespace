# Code of conduct

Notespace aims to provide a respectful, productive environment for users, contributors and maintainers.

## Expected behavior

- Discuss ideas and technical decisions on their merits; critique the work, not the person.
- Be constructive, precise, patient and receptive to feedback.
- Respect privacy, boundaries, differing experience levels and backgrounds.
- Keep issues and pull requests relevant to the project.

## Unacceptable behavior

Harassment, threats, discriminatory or degrading language, personal attacks, unwanted sexual attention, publishing another person's private information without permission, sustained disruption, and spam are not acceptable.

## Scope and enforcement

These expectations apply to project-managed issues, pull requests and related project interactions. Maintainers may remove inappropriate content, request changes in behavior, restrict participation or report serious abuse to GitHub. Decisions should be proportionate to severity and recurrence.

For ordinary moderation concerns, contact the [maintainer](https://github.com/howlil) through an available private channel. If none is available, request a contact channel without disclosing private details in public. Use [GitHub's abuse reporting tools](https://docs.github.com/en/site-policy/acceptable-use-policies/github-acceptable-use-policies) for platform-level abuse. Do not post sensitive evidence publicly.

This policy does not promise a particular response time. For security vulnerabilities, follow [SECURITY.md](SECURITY.md).
