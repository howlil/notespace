The [README](../README.md) is the project entry point. [DESIGN.md](../DESIGN.md) owns interaction and visual rules; [AGENTS.md](../AGENTS.md) directs engineering agents to the applicable contracts. The architecture and testing guides describe implementation and verification, not product promises.

For help, see [Support](../SUPPORT.md). For private vulnerability reporting, see [Security](../SECURITY.md). Published changes and downloadable installers are listed under [Releases](https://github.com/howlil/notespace/releases).

Documentation on the default branch may describe changes not yet available in the latest release. When reporting a problem, include your installed version or commit.
